How to install, understand, and use DeviceLifeline on Windows — the operating memory of your PC.

Overview

DeviceLifeline is a native Windows app that continuously captures what changed on your PC — software, configuration, performance, health, and crashes — so you can explain problems in plain language, clean up safely, and recover setups when something breaks.

  • Local-first. History lives in a SQLite database under your user profile.
  • No cloud chat required. Copilot uses offline heuristics, or optional on-device Qwen3.
  • Ops surface. Overview, Health, Performance, Storage, Cleanup, Processes, Drivers, Crashes, Recovery, and more in one shell.

Install

  1. Download the Windows installer from the product site (x64 setup for Windows 10 19041+ or Windows 11).
  2. Run the installer and follow the prompts. A black console window should not appear for normal installs.
  3. Launch DeviceLifeline from the Start menu. The first open loads the Overview dashboard.
Tip. Prefer the MSI or NSIS package from a trusted release folder. Sideload only builds you built yourself from this repository.

First run

After launch:

  1. Open Overview and click Run smart check. This samples CPU, memory, disk, and a light hardware pass without freezing the machine on a full SMART harvest.
  2. Review the health score, resource tiles, and any open findings.
  3. Use Ctrl+K (command palette) to jump to Health, Performance, Storage, Cleanup, Copilot, or Settings.
  4. Optional: open Settings → Theme to switch Light (default) or Dark.

Features

Health & Performance

Live metrics, health scores, alerts, sensors, clocks, and SMART disk identity. Full sensor packs run on Performance; smart check stays light on Overview.

Storage & Cleanup

Per-volume maps, large files, and safe cleanup categories with evidence paths — not vanity free-space theater.

Startup, Processes, Drivers

Control what runs at boot, inspect process risk signals, and review driver inventory with Windows Update driver install when available.

Crashes & Recovery

Crash events in plain English, Device DNA baselines, recovery vault, and restore plans when you need a way back.

Copilot

Copilot answers in plain English using telemetry on this PC. It never requires a cloud LLM API key for core use.

  • Heuristic mode works offline from samples and rules when no local model is installed.
  • Local Qwen3 (optional) runs via llama-server on your machine — install from Settings when free disk space allows (~1.5 GB free recommended).
  • Ask focused questions (“Why is C: full?”, “What changed yesterday?”) for the most useful answers.

Privacy & data

DeviceLifeline is designed so your PC history stays on your PC.

  • No cloud scanning of personal files for core product use.
  • Samples are system and inventory oriented (apps, config, metrics, crash logs).
  • Destructive actions (cleanup, restore) require explicit confirmation.
  • Exports are optional — you choose what to share.

More on the product site: Privacy principles.

FAQ

Does DeviceLifeline need the internet?

No for core health, storage, cleanup, and heuristic Copilot. Internet is only needed for downloads (app updates, optional local model, Windows Update driver install).

Why does Smart Check feel light on purpose?

A full SMART + sensor pack can freeze weaker PCs. Overview smart check uses a quick path; open Performance for deep sensors.

Where is my data stored?

Under the app data directory for your Windows user (local SQLite). It is not uploaded unless you export or enable a future sync feature.

Can I switch back to the dark UI?

Yes. Use the moon/sun control in the app header, or Settings → Theme → Dark.
